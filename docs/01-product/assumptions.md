# Assumptions

Các giả định cần được kiểm chứng dần, không xem như fact vĩnh viễn.

- Primary users là sinh viên/người mới học IT.
- Họ cần mental model tổng thể trước khi chọn hướng.
- Backend Java là phạm vi đủ hẹp để MVP có chiều sâu.
- Quỹ thời gian học thường biến động; soft scheduling hữu ích hơn deadline cứng.
- Curated official documentation + hướng dẫn đọc giúp giảm khó khăn khi tự học.
- Diagnostic ngắn hoặc có thể skip sẽ ít gây friction hơn bài test dài bắt buộc.
- Retrieval/review xen kẽ với kiến thức mới phù hợp mục tiêu ghi nhớ dài hạn.
- Rule-based planner đủ cho MVP và dễ giải thích trong đồ án.

Mỗi assumption quan trọng nên được gắn metric hoặc user test khi sản phẩm có người dùng thật.
