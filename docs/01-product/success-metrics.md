# Success Metrics

Không tối ưu chỉ cho time-in-app.

## Product metrics

- Onboarding completion.
- Explore → goal selection conversion.
- Diagnostic completion/skip rate.
- First learning session completion.
- Weekly active learners.
- Return after missed days.
- Learning-session abandonment point.

## Learning metrics

- Diagnostic-to-follow-up improvement per concept.
- Delayed recall accuracy.
- Weak-concept recovery rate.
- Guided → independent practice success.
- Mastery progression by concept.
- Review completion when due.

## Guardrail metrics

- % users accumulating “overdue debt” must remain near zero by design.
- % sessions exceeding selected time budget.
- Resource broken-link rate.
- Content correction rate.

Metrics definitions phải được mapping vào events trong `docs/05-data-ai/analytics-events.md`.
