# Feature Priority Matrix

Dùng MoSCoW để tránh mở rộng scope trong MVP.

## Must

- Authentication cơ bản
- Explore IT + role explanation
- Backend Java goal selection
- Diagnostic hoặc skip
- Concept graph + personal roadmap
- Today session
- Learning workspace
- Practice
- Assessment
- Mastery state
- Review scheduler + review session
- Progress
- Study preferences và soft rescheduling

## Should

- Resume session
- Lite session 10–15 phút
- Remediation after repeated mistakes
- Search/filter nhỏ trong roadmap
- Resource verification metadata

## Could

- AI explanation
- AI hint
- Exercise variants generated from approved template
- Optional weekly summary

## Won't in MVP

- Multi-career content breadth
- Live class
- Community/social feed
- Leaderboard
- Payment/subscription
- Native mobile
- Complex recommendation ML
- Microservices
- Full CMS
- Browser-based cloud IDE

## Scope rule

Một feature mới chỉ được vào MVP nếu nó giải quyết trực tiếp một critical user journey và có thể loại bỏ/hoãn một item tương đương để giữ scope.
