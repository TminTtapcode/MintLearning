# Product Risks

| Risk | Impact | Early mitigation |
|---|---|---|
| Curriculum quá rộng | Không hoàn thành MVP | Chỉ Backend Java Foundation |
| Content lỗi thời | Dạy kiến thức sai/cũ | `lastVerifiedAt`, ưu tiên official docs |
| Diagnostic đánh giá quá mạnh | User bị skip nền tảng cần thiết | Confidence + quick re-check |
| Planner quá cứng | User nản | soft schedule, reschedule |
| Review quá nhiều | Cản trở học mới | daily review budget |
| Mastery score tạo cảm giác giả chính xác | User/agent hiểu sai | state + score chỉ là heuristic |
| AI hallucination | Sai kiến thức | AI không là source of truth |
| UI quá nhiều dashboard | Cognitive overload | Today là home đơn giản |
| Over-engineering | Sinh viên không hiểu code | architecture simplicity rules |
| Auth/security làm muộn | Lộ learner data | server-side ownership từ đầu |
