# EPIC-04 — Learning Workspace

## User outcome

Một unit có đủ học liệu, example, practice và check.

## In scope

See `docs/01-product/feature-catalog.md` and relevant UX screen specs.

## Acceptance criteria

- **AC-01:** Unit shows why-it-matters and objectives.
- **AC-02:** Resource includes exact focus/skip notes.
- **AC-03:** Worked example appears before harder novice practice where applicable.
- **AC-04:** Progress can resume safely after page reload/session return.
- **AC-05:** Completing resource alone does not mark concept mastered.

## Cross-functional checks

- Product/business rules referenced.
- Learning rule checked if learner state/content changes.
- Loading/empty/error/resume state handled where applicable.
- Ownership enforced server-side.
- Relevant analytics event added.
- Tests cover authoritative behavior.

## Out of scope

Do not expand this epic with social, payments, ML, microservices or unrelated admin tooling.
