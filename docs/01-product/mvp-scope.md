# MVP Scope

## In scope

- Authentication/basic profile.
- Explore IT architecture.
- Backend Java Foundation goal.
- Diagnostic v1.
- Knowledge graph v1.
- Personal roadmap.
- Today session planner v1.
- Learning workspace.
- Curated resources.
- Worked examples.
- Guided + independent practice.
- Assessment.
- UserConceptState/mastery v1.
- Review scheduler v1.
- Progress view.
- Soft rescheduling.

## Explicitly out of scope

- Social feed/community.
- Leaderboard.
- Native mobile apps.
- Marketplace.
- Real-time pair programming.
- Complex ML recommendation.
- Microservices.
- Kafka/Kubernetes.
- Multiple fully-produced career paths.
- AI-generated curriculum without human curation.
