# User Journeys

## Journey A — First-time beginner

`Landing → Explore IT → Click Backend → View request/response flow → Compare roles → Choose Backend Java → Diagnostic or Start Basic → Initial Roadmap → Today → Learning Unit → Practice → Check → Review scheduled`

## Journey B — Learner already knows basics

`Choose Backend Java → Diagnostic → Known concepts marked with confidence → Gaps identified → Roadmap starts near first meaningful gap → User may challenge “I know this” with quick check`

## Journey C — Returning after absence

`Open app → Welcome back → Quick recall on due/fragile concepts → Planner rebalances → Today Lite/Normal options → Continue`

## Journey D — Curious exploration

`Roadmap → click locked/later concept → Preview purpose + prerequisites → user can explore without changing current plan`

## Journey E — Wrong answer remediation

`Assessment incorrect → classify misconception → explanation/hint → targeted practice → short re-check → update mastery → continue or schedule revisit`
