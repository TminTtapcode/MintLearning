# Open Questions

Chỉ giữ những câu hỏi chưa quyết định thật sự. Khi chốt, chuyển quyết định vào `decision-log.md` hoặc ADR tương ứng.

1. MVP có cần email verification hay chỉ local account cho demo?
2. Practice coding sẽ là text/code answer đơn giản hay có runner? Khuyến nghị MVP: **không chạy code server-side**, chỉ code-reading/input answer/manual comparison để tránh sandbox complexity.
3. Resource video có được embed hay chỉ link? Khuyến nghị MVP: link/metadata trước.
4. Có cần Content Editor UI trong bản bảo vệ đồ án? Khuyến nghị: không bắt buộc; YAML seed + admin read-only đủ.
5. Mastery score có hiển thị số % cho user hay chỉ state? Khuyến nghị: UI ưu tiên state, % dùng nội bộ/debug.
