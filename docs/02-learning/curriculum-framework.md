# Curriculum Framework

## Curriculum hierarchy

`Career Goal → Competency → Concept → Learning Objective → Learning Unit → Evidence`

## Backend Java Foundation competency groups

1. System/Web mental model
2. Programming foundations
3. Java language
4. Object-oriented design basics
5. Version control
6. Relational data/SQL
7. Networking & HTTP
8. REST/API design
9. Spring Boot/MVC
10. Persistence/JPA
11. Auth/security fundamentals
12. Testing
13. Container/deployment fundamentals
14. Integrated project work

## Concept quality checklist

Một concept phải:

- Có định nghĩa ngắn.
- Có scope boundary (bao gồm/không bao gồm).
- Có prerequisites.
- Có 1–4 measurable learning objectives.
- Có evidence type phù hợp.
- Có difficulty band.
- Có resource coverage.

## Sequencing rule

Graph đưa ra recommended order. UX không dùng graph để “cấm” người học xem concept; planner dùng graph để tránh giao task mới khi prerequisite evidence quá yếu.
