# Assessment Strategy

## Assessment purposes

- Diagnostic
- Formative check
- Mastery evidence
- Delayed review
- Remediation re-check

## Item types

- Short recall
- Multiple choice có distractor dựa trên misconception
- Scenario interpretation
- Code reading
- Debugging
- Small implementation task
- Explain-in-own-words (human/AI assisted evaluation only with rubric)

## Rules

- Không dùng MCQ cho mọi objective.
- Mỗi question map tới concept/objective.
- Wrong answer phải lưu error category nếu xác định được.
- Hint usage giảm strength của evidence nhưng không xóa learning value.
- Re-check nên dùng variant, không lặp nguyên câu ngay lập tức.

## Passing

Không có một threshold duy nhất cho mọi concept. Mastery calculation xem `docs/02-learning/mastery-model.md` và `docs/05-data-ai/mastery-calculation.md`.
