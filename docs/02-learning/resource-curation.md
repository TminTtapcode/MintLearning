# Resource Curation Guidelines

## Source priority

1. Official documentation/specification.
2. High-quality academic/educational source.
3. Maintainer-authored guides.
4. Community tutorial nếu rõ tác giả, cập nhật và được review.

## Required metadata

- title
- url
- sourceType
- language
- difficulty
- conceptsCovered
- estimatedReadMinutes
- focusSections
- skipSections
- verifiedAt
- notes

## Curation rule

Không chỉ lưu link. Learning Unit phải nói:

- đọc phần nào hôm nay;
- mục tiêu đọc;
- phần nào chưa cần;
- thực hành gì ngay sau đó.

## Freshness

Technical docs phải có `verifiedAt`. Broken/outdated link là Learning QA defect.

## AI rule

AI có thể tóm tắt resource đã xác minh nhưng không tự bịa citation/resource hoặc thay official behavior bằng trí nhớ mô hình.
