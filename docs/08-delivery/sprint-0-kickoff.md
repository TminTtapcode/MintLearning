# Sprint 0 / Product Foundation Kickoff

Sprint 0 is documentation/prototype/technical-foundation work, not a feature-release sprint.

## Goal

Reach a state where EPIC-01 Explore & Direction can enter development without foundational ambiguity.

## Product

- Validate target personas P1/P2.
- Review MVP boundaries.
- Convert EPIC-01 into feature specs + acceptance criteria.

## Learning

- Approve the system/web mental model concepts.
- Draft the first 15–25 concept nodes and prerequisite edges needed for Explore + early roadmap.
- Review example HTTP learning unit.

## UX

- Prototype primary tabs.
- Prototype Explore architecture interaction.
- Prototype onboarding → goal → diagnostic choice → Today.
- Test with at least a small set of representative users before visual polish.

## Architecture

- Finalize repository layout.
- Scaffold React + Spring Boot + MySQL local integration.
- Decide exact framework versions and record them.
- Create migration baseline.
- Establish API error/auth conventions.

## QA

- Turn acceptance-test catalog into executable test targets as modules appear.
- Establish test commands and fixture strategy.

## DevOps

- Basic CI for build/test.
- Do not spend Sprint 0 on Kubernetes/microservices.
- Dockerize after integrated local path is proven or near the end of foundation work.

## Exit criteria

- Product/learning/UX agree on EPIC-01 behavior.
- Repo builds locally.
- MySQL connection + migration baseline works.
- CI runs basic frontend/backend checks.
- One approved vertical-slice plan exists for implementation.
