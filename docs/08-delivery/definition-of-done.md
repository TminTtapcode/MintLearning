# Definition of Done

Feature chỉ Done khi applicable items thỏa:

- [ ] Acceptance criteria pass.
- [ ] Vertical behavior frontend/backend/data hoàn chỉnh.
- [ ] Business/learning rule authoritative nằm server-side nơi phù hợp.
- [ ] Unit/integration tests cho state transition quan trọng.
- [ ] Loading/empty/error/resume states handled.
- [ ] Authorization/ownership negative case checked.
- [ ] Accessibility baseline checked.
- [ ] Analytics event chỉ thêm nếu spec cần, không gửi raw private answer mặc định.
- [ ] Mastery/review/planner side effects verified nếu có.
- [ ] Content QA pass nếu có published learning content.
- [ ] Curriculum/schema validation pass nếu data thay đổi.
- [ ] Backend/frontend build green.
- [ ] Docs/ADR updated nếu behavior/architecture changed.
- [ ] Không có debug secret, bypass, TODO blocker hoặc hard-coded user id.

Compilation alone is not Done.
