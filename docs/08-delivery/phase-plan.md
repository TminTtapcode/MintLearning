# Product Development Phase Plan

## Phase 0 — Discovery

Deliverables: vision, personas, problems, learning principles, evidence base, success metrics, assumptions/risks.

Exit checklist: `checklists/phase-0-exit.md`.

## Phase 1 — Product Definition

Deliverables: PRD, FR/NFR, business rules, feature catalog/priority, journeys, information architecture, MVP scope.

Exit checklist: `checklists/phase-1-exit.md`.

## Phase 2 — Learning Architecture

Deliverables: concept taxonomy/graph, Backend Java YAML seed, learning unit/evidence/mastery/review/remediation/resource rules, sample end-to-end unit.

Exit checklist: `checklists/phase-2-exit.md`.

## Phase 3 — UX Architecture

Deliverables: IA, low-fi wireframes, screen contracts, prototype, usability test findings.

Documentation can be complete before user testing, but Phase 3 execution is not CLOSED until target-user testing occurs.

Exit checklist: `checklists/phase-3-exit.md`.

## Phase 4 — Technical Foundation

Deliverables: repo scaffold, React shell, Spring Boot baseline, MySQL/Flyway, auth baseline, error model, module boundaries, CI, fresh-clone smoke.

Exit checklist: `checklists/phase-4-exit.md` and `phase4-bootstrap-checklist.md`.

## Phase 5 — Vertical MVP Slices

Implement in order:
1. Explore + Goal.
2. Curriculum Graph + Roadmap.
3. Diagnostic.
4. Learning Workspace.
5. Assessment + Evidence.
6. Mastery + Review.
7. Today Planner.
8. Progress + Recovery.

Each slice must satisfy Definition of Ready/Done; do not implement backend for all epics first and frontend later.

## Phase 6 — Alpha

5–10 target learners. Observe usability, content clarity, learning-flow failures and recovery behavior.

## Phase 7 — Closed Beta

Measure product + learning metrics, fix retention/usability/content issues, then consider adding another learning path.

## Current readiness

See `phase-0-4-readiness.md`. Documentation readiness is not the same as implementation/user-testing closure.
