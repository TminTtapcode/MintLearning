# Phase 1 — Product Definition Exit Checklist

- [ ] PRD complete
- [ ] Functional and non-functional requirements documented
- [ ] Business rules documented
- [ ] Feature catalog and MVP priority documented
- [ ] Primary user journeys documented
- [ ] 6-tab information architecture documented
- [ ] Out-of-scope explicit
- [ ] Critical feature acceptance intent clear

## Closure rule

Không tick dựa trên dự định. Tick chỉ khi artifact/evidence thật tồn tại. Nếu một mục không áp dụng, ghi lý do thay vì xóa im lặng.
