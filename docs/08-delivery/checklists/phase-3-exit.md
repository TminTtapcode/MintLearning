# Phase 3 — UX Architecture Exit Checklist

- [ ] Information architecture documented
- [ ] Core wireframes exist
- [ ] Screen specs exist for critical flows
- [ ] Design system baseline exists
- [ ] Usability test plan/script exists
- [ ] Prototype available
- [ ] Target-user usability testing executed
- [ ] Critical/High findings resolved or intentionally accepted

## Closure rule

Không tick dựa trên dự định. Tick chỉ khi artifact/evidence thật tồn tại. Nếu một mục không áp dụng, ghi lý do thay vì xóa im lặng.
