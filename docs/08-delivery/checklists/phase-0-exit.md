# Phase 0 — Discovery Exit Checklist

- [ ] Product vision approved
- [ ] Primary target users/personas documented
- [ ] Core problems documented
- [ ] Learning principles/evidence base documented
- [ ] Success metrics defined
- [ ] Assumptions/risks/open questions documented

## Closure rule

Không tick dựa trên dự định. Tick chỉ khi artifact/evidence thật tồn tại. Nếu một mục không áp dụng, ghi lý do thay vì xóa im lặng.
