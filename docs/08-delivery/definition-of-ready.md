# Definition of Ready

Một story/vertical slice chỉ Ready khi applicable items đủ:

- [ ] User problem/outcome rõ.
- [ ] Epic/feature spec hoặc business rule reference.
- [ ] Acceptance criteria testable.
- [ ] Learning objective/rule nếu learner state/content thay đổi.
- [ ] Screen spec/flow và required states nếu có UI.
- [ ] API/data expectation nếu cross-layer.
- [ ] Authorization/ownership requirement.
- [ ] Edge cases quan trọng.
- [ ] Dependencies known.
- [ ] Open decision không còn blocker.
- [ ] Team hiểu solution ở mức không cần thêm infrastructure speculative.

Bug nhỏ không cần bureaucracy đầy đủ, nhưng critical behavior phải trace được tới expected outcome.
