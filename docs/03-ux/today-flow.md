# Today Flow

## Page objective

Trả lời duy nhất: **“Hôm nay tôi nên làm gì?”**

## Layout priority

1. Available-time selector / current plan.
2. Review summary.
3. New concept.
4. Practice.
5. Check.
6. Primary CTA `Start session` / `Continue session`.

## Session modes

- 10 min: review + micro-practice.
- 30 min: review + one focused learning/practice block.
- 60 min: standard mixed session.
- Custom: planner fits content within budget.

## Constraint

Planner không được tạo session có expected duration vượt budget đáng kể; nếu không fit, giảm scope, không ép user.
