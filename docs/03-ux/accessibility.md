# Accessibility Baseline

## MVP requirements

- Semantic HTML.
- Heading hierarchy hợp lý.
- Form controls có label.
- Visible keyboard focus.
- Core navigation dùng keyboard được.
- Status không truyền chỉ bằng màu/icon.
- Error message gắn với field.
- Diagram quan trọng có text explanation tương đương.
- Motion không bắt buộc để hiểu thông tin.

## Testing

Frontend QA phải có keyboard pass cho onboarding, Today, Learning Unit và Assessment.
