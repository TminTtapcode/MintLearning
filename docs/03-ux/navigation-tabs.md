# Navigation & Tabs

## Primary tabs — MVP

1. **Explore** — hiểu hệ thống IT và roles.
2. **Today** — việc nên làm hôm nay; default landing sau onboarding.
3. **Roadmap** — graph/progression và preview.
4. **Learn** — learning workspace/library context; active unit resume.
5. **Review** — due/fragile concepts.
6. **Progress** — mastery/progress trends.

Profile/Settings nằm trong account menu, không chiếm primary tab.

## Rules

- Không thêm tab mới nếu có thể là sub-route/contextual action.
- Today là action-oriented; Progress là reflection-oriented.
- Learn không thay Today: Today chọn session, Learn thực thi unit.
- Review có dedicated entry nhưng planner vẫn có thể embed review trong Today.
