# Usability Test Script

## Intro

“Bọn mình đang test sản phẩm, không test bạn. Nếu có chỗ khó hiểu thì đó là dữ liệu để bọn mình sửa giao diện.”

## Rules

- Không hướng dẫn cách làm trừ khi participant bị kẹt hoàn toàn.
- Khuyến khích think-aloud: nói điều họ đang nghĩ.
- Không giải thích feature trước khi participant tự nhìn thấy.

## Questions after tasks

- Bạn nghĩ tab này dùng để làm gì?
- Có điểm nào khiến bạn cảm thấy bị bắt buộc không?
- Bạn có hiểu hôm nay tại sao hệ thống đề xuất hoạt động này không?
- Bạn có hiểu “Review due” khác “chưa hoàn thành” không?
- Nếu nghỉ 5 ngày, bạn mong hệ thống làm gì?

## End

Hỏi 3 câu:
1. Phần hữu ích nhất?
2. Phần khó hiểu nhất?
3. Bạn có biết bước tiếp theo phải làm gì không?
