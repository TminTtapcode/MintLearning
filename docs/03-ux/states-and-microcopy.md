# UI States & Microcopy

## Mandatory state set

Mọi feature async/list/detail quan trọng phải xem xét:

- loading
- success
- empty
- partial
- error
- retry
- offline/connection issue nếu phù hợp
- resume/in-progress nếu có session state

## Learning copy rules

- Không dùng “lazy”, “failed learner”, “behind”.
- Wrong answer = signal để điều chỉnh.
- Lock icon nếu dùng phải có explanation và preview path.
- Score không nên đứng một mình; kèm concept feedback.

## Empty examples

Review empty: `Hôm nay chưa có kiến thức nào cần ôn. Bạn có thể tiếp tục bài mới.`
Progress empty: `Hoàn thành buổi học đầu tiên để bắt đầu hình thành bản đồ tiến độ.`
