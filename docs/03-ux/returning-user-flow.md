# Returning User / Missed Days Flow

## Trigger

User quay lại sau thời gian dài hơn lịch học thông thường hoặc có nhiều review due.

## Flow

1. Welcome back, không guilt.
2. Hỏi available time hôm nay.
3. Quick recall một số fragile prerequisite nếu cần.
4. Recalculate learner state/priority.
5. Rebalance plan; không tạo stack overdue.
6. Bắt đầu session nhỏ có khả năng thành công.

## Copy examples

- `Chào mừng bạn quay lại. Hôm nay mình bắt đầu bằng một lượt ôn ngắn.`
- `Kế hoạch tuần đã được sắp lại; bạn không cần học bù từng task đã bỏ lỡ.`
