# Learning Workspace

## Information order

1. Title + progress inside current unit.
2. Why it matters.
3. Objectives.
4. Learn resource + focus instructions.
5. Explanation/diagram.
6. Worked example.
7. Guided practice.
8. Independent practice.
9. Retrieval check.
10. Feedback + next action.

## Interaction rules

- Autosave attempt/progress.
- `Continue where you left off` khi quay lại.
- Hint theo cấp độ; không dump answer ngay.
- Resource mở trong safe context/tab nhưng app giữ objective visible.
- Có “I’m confused” path để xem prerequisite/explanation khác.

## Completion

Unit completion UI phải tách:

- `Session done`
- `Concept state updated`
- `Next review` nếu có

Không nói “Mastered” chỉ vì user đã xem hết.
