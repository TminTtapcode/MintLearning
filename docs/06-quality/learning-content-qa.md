# Learning Content QA

## Review checklist

- Technical statement đúng và phù hợp version/context.
- Learning objective measurable.
- Prerequisites hợp lý.
- Resource link còn hoạt động.
- Focus/skip sections có ý nghĩa.
- Worked example đúng.
- Exercise solvable từ kiến thức đã cung cấp.
- Answer key/rubric đúng.
- Difficulty phù hợp.
- Feedback không lộ đáp án quá sớm.
- Terminology nhất quán glossary.

## AI-generated content

Không publish trực tiếp. Phải qua schema validation + content review; với technical behavior nên kiểm tra official docs/source.
