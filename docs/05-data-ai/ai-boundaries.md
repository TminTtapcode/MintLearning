# AI Boundaries

## AI may

- Giải thích lại một concept từ curated source/context.
- Tạo hint theo rubric.
- Tạo exercise variant rồi qua validation/rules.
- Phân loại error pattern hỗ trợ feedback.
- Tóm tắt learning resource đã xác minh.

## AI may not be sole authority for

- Curriculum ordering.
- Prerequisite truth.
- Official API/framework behavior.
- Mastery decision không có evidence/rule.
- Security authorization.
- Publishing technical content không review.

## Fallback

Nếu AI unavailable, core learning flow phải vẫn hoạt động với curated content + deterministic assessment/planner v1.

## Evaluation

Mọi AI feature cần:

- clear task definition
- expected output schema/rubric
- failure examples
- human-review policy cho content publishing
- metrics
