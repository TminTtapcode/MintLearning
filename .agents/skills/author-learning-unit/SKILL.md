# Author Learning Unit

Read:
- `docs/02-learning/learning-unit-spec.md`
- `docs/02-learning/resource-curation.md`
- `docs/02-learning/assessment-strategy.md`
- `docs/02-learning/learning-unit-authoring-guide.md`
- `docs/02-learning/content-quality-rubric.md`
- `curriculum/backend-java/concepts.yaml`
- `docs/99-templates/learning-unit-template.md`

Process:
1. Define concept scope and prerequisite.
2. Write measurable objectives.
3. Select authoritative resources and exact focus sections.
4. Explain why the concept matters in the system.
5. Provide worked example.
6. Create guided practice then independent practice.
7. Create retrieval check aligned to objectives.
8. List common misconceptions and remediation.
9. Define evidence and review intent.
10. Run Learning QA checklist before publish.
