# Documentation Rules

- Update the canonical source file, not duplicate facts across many docs unnecessarily.
- New architecture decision with meaningful trade-off → ADR.
- New cross-domain product decision → decision log.
- Use glossary terminology consistently.
- Requirements should be testable; use Given/When/Then for critical acceptance criteria.
- Do not mark undecided choices as approved facts.
