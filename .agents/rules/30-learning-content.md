# Learning Content Rules

Read `docs/02-learning/` before changes.

- Every learning unit needs objective, resource focus, example, practice, assessment evidence and review intent.
- Resource link alone is not a lesson.
- Prefer curated/official technical sources.
- Do not personalize by unsupported learning-style labels.
- Novice content should scaffold from example toward independent work.
- Wrong answers should map to actionable remediation where possible.
- Never claim evidence proves universal learning effectiveness.
