# Core Rules

Read `AGENTS.md` before meaningful changes.

- Product loop: Explore → Choose → Diagnose → Plan → Learn → Practice → Assess → Review → Adapt.
- Completion is not mastery.
- Missed days trigger re-planning, not overdue debt.
- Prerequisites guide sequencing; users may preview concepts.
- AI is assistant, not curriculum/security authority.
- MVP is Backend Java Foundation, modular monolith, React + Spring Boot + MySQL.
- Do not introduce new infrastructure/frameworks without a documented need/decision.
- Verify acceptance criteria and Definition of Done before declaring completion.
