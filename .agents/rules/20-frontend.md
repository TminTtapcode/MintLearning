# Frontend Rules

- Primary tabs remain Explore, Today, Roadmap, Learn, Review, Progress unless Product spec changes.
- Handle loading, empty, error and resume/in-progress states where applicable.
- Do not compute authoritative mastery or authorization in the client.
- Do not hard-code curriculum sequence into components.
- Avoid shame/overdue/streak-pressure copy.
- Core interactions must remain keyboard accessible.
- Today page must keep one obvious primary next action.
